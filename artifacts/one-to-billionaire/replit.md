# $1 to Billionaire

A premium, rapid-fire fictional wealth game where each choice is a dramatic chance at turning one dollar into an empire. 

## Run Instructions

1. Start the Expo development server:
```bash
cd artifacts/one-to-billionaire
npm run dev
```

2. Open the app:
- **Web**: Replit webview will automatically open the app.
- **Mobile**: Scan the QR code with Expo Go on your mobile device.

## Features
- Deeply replayable card-swiping style decision mechanics
- 80+ handcrafted scenarios across 6 net-worth tiers
- Passive income from acquired businesses and assets
- Risk management (0-100) affecting outcomes
- 20 unlockable achievements
- Bankruptcy mechanics with a Second Chance (rewarded ad mock)
- Haptics, animated counters, smooth UI
